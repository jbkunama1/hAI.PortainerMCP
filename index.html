How it works

Ein MCP-Server, viele Portainer-Instanzen – angesprochen per Alias.

MCP client / AnythingMCP / Agenten
streamable HTTP → :8025/mcp
portainer-mcp  :8025
Portainer REST API v2 + X-API-Key
Portainer-1 · Portainer-2 · … · Portainer-20
Admin-Webseite  :8026
CRUD → data/portainer_aliases.json (homelab, prod, …)

Features

Alles, was die README verspricht, auf den Punkt.

🏠 Alias-Verwaltung

Verwalte bis zu 20 Portainer-Instanzen unter einem Alias (homelab, prod, …). API-Key pro Instanz, gespeichert in data/portainer_aliases.json.

🧠 MCP-Tools für Agents

portainer_alias_list/add/update/remove, portainer_status, portainer_endpoints, portainer_containers_list, portainer_stacks_list.

🛠️ Admin-Webseite

Passwortgeschützte Seite auf 8026: Aliase anlegen, bearbeiten, löschen – ohne Datei-Editor. Login via HttpOnly-Cookie.

🚀 Docker + Portainer

Published als ghcr.io/jbkunama1/hai.portainermcp:latest, deploybar als Stack – mit Volume für die Alias-Datei.

📈 streamable HTTP

AnythingMCP zeigt auf http://<host>:8025/mcp. Kein stdio, kein Build im Agent-Kontext.

🔐 TruffleHog-Scan

GitHub-Actions-Workflow prüft bei jedem Push/PR auf versehentlich eingecheckte Secrets.

Deploy

In Portainer: Stacks → Add stack → Repository, URL, Compose-Pfad docker-compose.yml, Branch main.

# docker network create highfishNetwork
services:
  portainer-mcp:
    image: ghcr.io/jbkunama1/hai.portainermcp:latest
    container_name: portainer-mcp
    restart: unless-stopped
    networks: [highfishNetwork]
    ports:
      - "8025:8025"   # MCP (streamable HTTP)
      - "8026:8026"   # Admin-Webseite
    volumes:
      - ./data:/usr/src/app/data
    environment:
      PORTAINER_ADMIN_PASSWORD: "CHANGE_ME_ADMIN"

networks:
  highfishNetwork:
    external: true
