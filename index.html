hAI.PortainerMCP

Auth-layered MCP SSH gateway – Alias‑basierte Verwaltung von Portainer-Instanzen

Deploy on GitHub Deploy with Portainer

Wie es funktioniert

Der MCP‑Server empfängt Anfragen über http://localhost:8822/mcp und leitet sie an den internen sshmcp-core weiter. Alle Alias‑Konfigurationen werden in data/ssh_aliases.json gespeichert.

Funktionen

  • 🔒 API‑Schlüssel Authentifizierung (keine Passwörter im Code)
  • 📦 SSH‑Alias‑Registry (bis 20 Einträge)
  • 🖥️ Admin‑UI & CLI über http://localhost:8825
  • 🐳 Docker‑Komposition mit highfishNetwork
Node.js – Leichtgewichtig
Docker – Container‑Ready
Portainer – Direkter Zugriff

Deployment

Kloniere das Repository und starte mit:

docker-compose up -d

Für Portainer: Stack erstellen unter Settings → Stacks → Add stack.
